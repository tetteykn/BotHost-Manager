# BotHost Manager

**BotHost Manager** is a desktop control panel for your Discord bot. Connect your bot token, pick a server, and start or stop the bot — no coding or command line needed. From the same app you control who may use each command, edit welcome and goodbye messages, greetings and bad words, set up Warface crown missions, and manage activation, all per server.

---

## Key Features

### Run any Discord bot, no code
- Paste your bot token and pick the server it should work in.
- Start and stop the bot with one click — the bot runs in the background and its log is shown in the app.

### Per-command permissions
- Decide who may use each command: everyone, the bot owner only, or the owner plus chosen roles and users.
- Decide where each command works: all channels, or only the channels you tick.

### Welcome, goodbye & greetings
- Set custom join and leave messages, greeting trigger words and replies, and a bad-words filter.
- All configured per server, with simple word-list editors.

### Warface crown missions
- Add, edit and delete the missions, scores and times shown by `/warface_crown`, for each difficulty.

### Moderation built in
- Timeout users, delete messages, set slow mode, and give roles with staff commands.

### Gold & level economy
- A full economy for your members: a shop, items, gambling, gold transfers and profile lookups, with levels and EXP.

### Anti-spam
- Automatic message and link spam protection with configurable limits and role/user exemptions.

### Themes & tray
- Dark, Grey and Light themes, minimize/close to tray, and optional run at startup.
- The bot keeps running while the app sits in the tray.
